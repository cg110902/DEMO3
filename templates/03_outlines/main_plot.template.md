# 全书主线与三级节奏大纲 (Main Plot Outline)

## 一、 全书核心主线与长线终极悬念 (Grand Arc)
- **终极主线**：[主角从底层微末起步，历经多阶段成长，解开世界终极隐秘，重塑天地秩序]
- **宏观世界暗流**：[跨越全书的深层矛盾：古老道统断绝 / 异维魔渊侵蚀 / 星际文明大过滤器]
- **主角成长轴（可自定义，不限于 Stage 0~4）**：[如：底层求生 → 立足积累 → 信息做庄 → 规则重塑 → 自我超越；或信任/认知/地位等其他轨道；也可采用“反成长/稳定型”设计。登记进 `project_bible.md` 与 `character_growth_arcs.json`。]

## 二、 全书分卷波浪规划 (Multi-Volume Roadmap)

### 第 1 卷：[《首卷卷名》· 起始破局与立足基本盘 (1~30章)]
- **核心矛盾**：[底层生死危机，击碎直接压迫势力，建立自己的第一个立足点与基本盘]
- **本卷成长/推进（战力/阶层/认知/资源/关系等）**：[层级一 → 层级二巅峰]
- **卷终高潮点**：[全城/区域决战，扫清障碍，获得通向更高舞台的门票]

### 第 2 卷：[《第二卷卷名》· 势力争渡 / 区域风云 / 跨区开拓 (31~70章)]
- **核心矛盾**：[跨入更大地缘/星系/组织舞台，大选试炼或重大事件，破获更深层阴谋]
- **本卷成长/推进（战力/阶层/认知/资源/关系等）**：[层级二 → 层级三]

### 第 3 卷：[《第三卷卷名》· 阵营博弈与乱世定鼎 (71~120章)]
- **核心矛盾**：[多方超级大势力全面冲突，幕后做庄，主导天下大势]

### 第 4 卷及终卷：[《终卷卷名》· 终极真相对决与重塑乾坤 (121~200章+)]
- **核心矛盾**：[直面世界底层因果与终极大劫，终极闭环]

# 全题材长线叙事与节奏控制规范

> 长线叙事大多是**开放类**：核心不变量极少（因果一致、变化有代价、伏笔可回收、节奏有“波形”而非“计数”），其余全是默认与参考。**请把本文当作“可调用的创作模型库”，而不是“每章必须完成的检查表”。**

> **多样化推演**：写作时主动换“节奏波形、期待架构、成长轴、叙事线组合、死线形态”，避免同一套“三线+阶梯+死线”模板被重复生成。只要结构在**情绪与因果上成立**，就允许是新形态。

---

## 一、 期待感模型 (📐 T1 默认 / 🧭 T2 参考)

> **判据**：读者之所以翻页，是因为此刻有“一个想被满足的期待”。期待可以是目标、威胁、悬念、情绪或生活的小谜题。**下面三层只是最常见的拆法，不是“缺一不可”。**

| 层级 | 名称 | 内容 | 说明 |
|------|------|------|------|
| L1 | 显性目标 | 当前正被追求的具体目标（夺宝/破案/谈判/比赛/救人/探索/做一顿饭） | 所有题材适用，目标类型由题材决定 |
| L2 | 隐性危机 | 读者知道但角色不知道的威胁（密谋/误会/伏笔/倒计时/人际暗流） | 所有题材适用，危机类型由题材决定 |
| L3 | 倒计时炸弹 | 明确的时间/资源/生命限制 | 无倒计时的题材（治愈/日常/文学）可弱化或跳过 |

### 执行原则
- 三层是“默认配比”，不是“必须同时出现”。**每章只要至少有一个真正调动读者情绪的期待在运转即可**；可以是 L1、L2、L3 中的任意组合。
- 常见的默认组合：商业冲突章 = L1+L2+L3；情感章 = L1+L2；日常/治愈 = L1（+L2 的人际暗流）即可成立。
- 允许完全不同的期待架构：**悬念后置**（先给反常再给目标）、**情绪主导**（读者期待的不是“赢”，而是“某种关系落点”）、**氛围主导**（恐怖/治愈靠未知与共鸣而非明确目标）。
- 若某章刻意减少期待（慢章、过渡章、休息章），请确保它仍承担“铺垫/蓄力/换气”功能，且别连续多章无期待。

## 二、 能力/成长阶梯与推演锁 (📐 T1 默认 / 🔒 T0 防无因暴涨)

> **判据（T0）**：任何“变强”“变多”“变重要”都必须**有积累、有代价、有可感知的损耗**，避免凭空获得、避免数值无意义膨胀。**至于台阶长什么样、一次跨几级，是 T1/T2 默认与参考，不是铁律。**

> **关键澄清**：并不是所有书都是“升级式”成长。很多题材的“成长阶梯”是**认知、信任、技艺、资源、地位、觉悟**等软阶梯；也有些书根本不用阶梯（群像、解构、宿命、生活流）。**不要为了套阶梯而给不需要机制的故事硬造一套等级。**

### 常见“阶梯”形态（🧭 T2 参考，不穷举）
| 题材 | 常见阶梯 | 突破代价 |
|------|----------|----------|
| 玄幻/仙侠 | 境界（炼气→筑基→金丹→…） | 走火入魔/灵气反噬/心魔 |
| 武侠 | 武学层次 | 内力反噬/经脉受损 |
| 科幻/异能 | 异能/科技/等级 | 基因崩溃/义体损耗/精神污染 |
| 都市/职场 | 资源/人脉/权位 | 人脉损耗/资源耗尽/健康代价 |
| 悬疑/推理 | 认知/证据链/信任 | 认知过载/心理创伤/人身安全 |
| 言情/纯爱 | 关系深度（陌生→…→承诺） | 信任破裂/误会加深/情感创伤 |
| 游戏/体育/军事 | 段位/技术/军衔 | 伤病/状态下滑/心理/伤亡 |

### 推演锁（默认值，可被本书覆盖）
1. **默认**：单卷内跨越 1 个大阶梯或 2~3 个小阶梯比较稳；但这不是规则——**只要成长有过程、读者能感知“他没白变强”，单章大突破/多级连跳也允许**（前提是铺垫与代价到位）。若本书采用更慢/更快节奏，在 `project_bible.md` 写明。
2. **积累优先**：变强必须源于**本书定义的等价积累**（训练/科研/经验/情感沉淀/赌注/领悟），拒绝无因顿悟与天降外挂。
3. **代价真实**：突破带可感知损耗，突破后需恢复期；损耗形态按题材自定（灵气/体力/资源/健康/情感/信任/名声）。
4. **对手同步**：对手成长与主角成长保持“同辈张力”，可同速、可错位、可存在刻意不对等（如老谋深算的强敌），但**不能为了捧主角而无因降智/无因暴涨**。
5. **阶梯登记**：若本书采用阶梯，在 `world_rules.md` / `current_state.json` 定义名称与当前进度；若不用阶梯，记录“成长轴”名称即可（如“信任度”“认知线”）。

## 三、 经济数值防通胀 (Universal Economy Anti-Inflation)

> ⚠️ **适用范围**：有经济体系的题材（玄幻/都市/科幻/历史/游戏/军事/现实主义/无限流/轻小说）。无经济体系的题材（纯悬疑/纯爱/恐怖/治愈系，以及武侠/体育/规则怪谈等）由 `genre_profile.economy_required: false` 跳过。

### 核心规则
1. **购买力原点**：以底层普通人一餐一饭为购买力原点，确定货币换算体系。
   - 玄幻：1 文钱 = 1 个馒头；1 两银子 = 1000 文 = 普通人 2 个月生活费。
   - 都市：1 元 = 1 瓶水；普通人月薪 5000 元。
   - 科幻：1 信用点 = 1 份营养剂；底层工人日薪 50 信用点。
   - 历史：1 石米 = 普通人 1 个月口粮；1 两银子 = 2 石米。
2. **高阶资源稀缺性**：高阶资源（灵石/法宝/情报/专利/武器/土地）有真实的流动消耗闭环，不能无限产出。
3. **拒绝数字无限加零**：不能为了"显得厉害"就把金额从万加到亿加到兆。购买力锚定后，数字大小有真实意义。
4. **财富沉淀与流动**：主角获得的财富必须有去向（消费/投资/存储/损耗），不能只进不出。
5. **复式账本由引擎管理**：`economy_ledger.json` 由确定性引擎从流水重算，AI 只提 `transactions[]` 流水（delta 正收负支 + 事由），严禁手填余额。

## 四、 节奏波形 (📐 T1 默认 / 🧭 T2 参考)

> **判据**：读者需要“可感知的张弛变化”，而不是“均衡的平均密度”。什么算“紧”、什么算“松”，取决于**本书的既定情绪曲线**，不取决于固定章数。

### 默认三层尺度（仅作参考，可整体放慢/加快）
| 层级 | 大致跨度 | 内容 | 节奏 |
|------|----------|------|------|
| 短线（微拉扯） | 1~3 章 | 眼前冲突/对话/动作 | 紧：能感到推进 |
| 中线（小闭环） | 3~15 章 | 一个小目标达成/关系变化/小成长/环境变化 | 有紧有松 |
| 长线（大闭环） | 20~100+ 章 | 卷/幕的大兑现：真相、转机、成长质变 | 蓄力→爆发→余韵 |

### 可换着用的节奏波形（不穷举）
- **波浪形（默认）**：紧→松→再紧，高峰之间留缓冲，适合绝大多数商业长篇。
- **连珠炮**：连续高压，靠小转机/小喘息维持呼吸，适合惊悚、军事、无限流生存关。
- **双峰/多峰**：一场大冲突分两个波峰释放（先泄一半、再反转），适合权谋、政斗、群像。
- **长线压弯**：很长的松弛暗示，最后集中引爆，适合悬疑、现实主义、正剧。
- **碎片/生活流**：无强峰值，靠微小情绪与细节延宕，适合治愈、日常、散文向。
- **大线并行**：同一卷里几根线轮流推进、错峰兑现，适合多视角、群像、单元剧。

### 原则
- 默认“连续高压后给缓冲”，缓冲章**不是水章**，要为下一个高峰蓄力（铺线索/深化关系/展示代价/换气）。
- “大高潮”不一定是战斗，可以是真相揭露、情感爆发、关系转折、规则反转、生活事件、命运关口——**按本书主题定**。
- **不要机械数章数**（“第 5 章必须小高潮”）；只要读者能感到“起—伏—再起”的曲线，章数可被题材与风格拉长或压缩。

## 五、 伏笔网络与长线复利 (Universal Foreshadow Network)

### 伏笔三态
| 状态 | 标记 | 含义 |
|------|------|------|
| Planted | 埋下 | 新伏笔，预期在 target_ch 引爆 |
| Reminded | 回唤 | 临近引爆，提醒读者注意 |
| Resolved | 回收 | 已引爆/闭环 |

### 调度规则（由 `foreshadow_scheduler.py` 自动计算，属 🧭 参考/基线；以各题材档案 `scheduler` 字段为准）
- `remind_lead`：回唤提前量（默认 3 章；悬疑/规则怪谈/现实主义 4 章）。
- `dormant_gap`：沉睡容忍（默认 5 章；悬疑/规则怪谈/恐怖/无限流 4 章，现实主义 6 章，治愈系 8 章）。超过则报警。
- `longline_interval`：长线伏笔回唤周期（默认 8~12 章；悬疑/恐怖/规则怪谈/无限流 6~10 章，现实主义 10~15 章，治愈系 12~20 章）。
- 以上参数由 `genre_profile.scheduler` 控制，不同题材不同节奏；**也可因本书结构整体调整**，调整后在 `project_bible.md` 记录。

### 闭环承诺（🔒 T0：因果不悬空）
- **核心伏笔应可回收**：写进正文的因果线索，要么闭环，要么明确标记为长线/最终不了了之（并让读者意识到“作者故意不揭”）。**“不填坑”可以是被设计的世界观留白，但不能是无意识的弃坑。**
- **伏笔不冲突**：同一伏笔不能有两个互相矛盾的解释；若世界观本来就允许“多重解释”，要尽早建立“一切解释都存在矛盾”这一设定。
- **引爆要有铺垫（📐 默认）**：默认引爆前留 1~2 处隐性铺垫（流言/反常/失联/细节）让读者“回想得起、又没点破”；**若本章追求意外性/惊悚突袭，也可以少铺垫甚至零铺垫**，但需让事后回看仍能找到合理动机，不要让“毫无征兆”变成“都合主义”。

## 六、 角色弧线与成长轨迹 (🔒 T0 不变量 + 🧭 T2 开放自绘)

> **判据（T0）**：角色的认知、心性、防线、信念等长期状态**向前移动时必须有触发 + 过程 + 代价**；可以停滞、可以倒退、可以螺旋，但不能无因突变。所谓“当前阶段”**由本书自己定义**，不是套用某个固定编号。

### 📐 默认心智轴（T1，可覆盖，可修改，非唯一真理）
- 每个题材都不一样，大致上都是：生存 - 发展 - 追求更高目标 - 成为人上人；需要根据当前题材合理设计。

### 🧭 常见但可替换的成长轨道（不穷举）
- 言情：戒备 → 试探 → 信任 → 承诺 → 磨合（信任深度轴）
- 悬疑：困惑 → 怀疑 → 推翻 → 整合 → 直面（认知成熟轴）
- 治愈：回避 → 接触 → 接纳 → 融入 → 自洽（与世界和解轴）
- 反转/解构：坚定 → 动摇 → 破碎 → 重新定义（信念崩塌与重建轴）
- 群像/单元：无统一阶梯，各角色沿各自轨道、速度不同（认知差即张力）
- 稳定型/反成长：主角本就不变，靠**他人与世界的位移**映照“不变的可贵/可悲”

### 规则
- **本书若采用自定义轨道**：在 `project_bible.md` / `character_growth_arcs.json` 写明轨道名称、当前节点、位移触发事件与代价；登记后以它为判断依据。
- **跃迁需触发（T0）**：发生位移时不一定要“事件爆发”，但要有**足以解释的诱因**（经历、谎言、代价、陪伴、失败、顿悟）。
- **不同角色可不同轨道、不同步**：形成认知差与信息差，是戏剧张力的重要来源。
- **不要为“成长”而成长**：角色可以不成长、可以不救赎、可以不醒悟；只要结果与主题自洽即可。**“不写成长”也是合格的设计。**

## 七、 叙事线组合 (📐 T1 默认 / 🧭 T2 参考)

> **判据**：长篇需要一个“跨章的纵向结构”，让读者知道故事在往哪走、还有什么没被兑现。**但“至少三条线”只是常见做法，不是规则。** 线可以多、可以少、可以一条主线吃到尾。

### 常见组合（不穷举）
- **标准三线（默认）**：主线（成长/目标）+ 人际线（羁绊/博弈）+ 暗线（真相/伏笔）。适合绝大多数长篇。
- **单线深入**：一条主线贯穿，靠副线细节与人物密度支撑。适合单元剧、强情感、现实主义。
- **双线交替**：现在线 + 过去线 / 主角线 + 对手线 / 明线 + 暗线。适合悬疑、历史、言情往复。
- **群像/多线并行**：多主角、多阵营、多地图轮换，在卷末交汇。适合史诗、群像、单元副本。
- **事件/世界线**：无传统“主角目标”，以世界变化、时代变迁、事件推进为轴。适合文学向、历史、灾难题材。

### 规则
- **组合登记**：在 `project_bible.md`/卷纲写明本书的线结构与各线“再推进的周期”。
- 各线不必每章都出现，但要保证**卷内没被遗忘**；单线故事也要让“暗处”有呼应（不一定要专职暗线）。
- **交汇点**：卷/幕末让主线、人际、暗线（若有）有一次共振，制造“多件事是一件事”的纵深；不强行把不相关的线拧在一起。

## 八、 开局抓手 (📐 T1 默认：具象死线 / 🧭 T2 可变形态)

> **判据**：开局最有用的不是“规则”，而是**让读者立刻知道“我要跟着谁、他在乎什么、接下来会发生什么”**。这不一定靠倒计时危机。


### 原则
- **开局 3 章**是默认窗口，不是铁律；文学/日常/治愈可放宽。
- 无论哪种抓手，**都要尽早给出一个“该角色在乎的东西”**（目标、痛点、执念），否则读者没有代入支点。
- 允许“慢热但有味道”——只要前几章能持续提供看点（反差、秘密、氛围、关系），就不必硬塞死线。

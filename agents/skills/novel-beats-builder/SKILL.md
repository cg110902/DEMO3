# 单章细纲与多分支走向推演技能 (Novel Beats Builder & Branching Engine)

本技能作为单章起草前的情节构筑特工，负责将宏观主线大纲拆解推演为**分场景、高张力、强代入感、富有戏剧反差**的单章分场景 Beats 细纲。

> 💡 **【自由拼装与自主创新原则】**：
> 本技能所列的 4 维积木体系与 12 大看点维度，**均为启发式指导（包含但不限于文中列举的维度）**。推演特工在构思分场景时，**完全可以且被鼓励根据当前剧情心流与题材特色自主独创全新的场景切入、推进引擎、意外转折与情绪余韵**；所采取的结构设计完全可以是示例之外的例外，重点在于打造环环相扣、扣人心弦的阅读体验！
> **分级提示（见 AGENTS.md）**：🔥 不可变的是“变化有因果、有铺垫、可回看”；其余（看点维度、积木、转折、篇幅）都是默认/参考，可自由替换。**推演时请主动问“这次能不能用第 X 种完全不同的大门？”**，避免同一套结构被反复复用。

> **【全题材自适应】**：本技能适用于所有题材。看点维度、破局手段、节奏密度均由题材档案控制，编剧应根据具体题材灵活调整（如治愈系弱化冲突、言情强化情感张力、悬疑强化信息差）。

## 一、 执行第一步：一键装载动态语境 (Context Packager)

在推演细纲前，运行统一 CLI 装载全量事实与预警（支持 token 预算裁剪）：
```powershell
python studio.py pack ch_xxx --json [--budget 12000]
```
> 💡 `--budget` 为可选 token 预算（**默认 0=全量不裁**）。预算紧张时按优先级裁剪：本章细纲与高优先级预警绝不裁，人物卡最先被裁；被裁内容仍完整保留在工作区原文件中，`budget_report` 会列明裁掉了什么。语境无压力时不要传该参数。
**深度消费工具数据**：
- 提取 `high_priority_story_alerts`：优先在细纲中安排**【临界伏笔揭露】**与**【掉线角色唤醒】**；
- 提取 `foreshadow_schedule`（或单独运行 `python studio.py schedule ch_xxx`）：按调度建议规划本章应**引爆/回收**的到期伏笔、应**回唤**的临近伏笔与需**唤醒**的沉睡伏笔；
- 提取 `synopsis_spine`（全书梗概脊柱）与 `cross_chapter_warnings`（跨章重复预警，可运行 `python studio.py memory repeat` 深度检测）：避免重复已写过的场景桥段与人设介绍；
- 提取 `librarian_recall`（或运行 `python studio.py memory recall "关键词"`）：回捞最相关的旧伏笔、人物与设定细节；
- 提取 `current_state` 与 `character_growth_arcs`：确保在场角色行为符合其当前心智阶段（Stage 0/1/2...）；
- 提取 `active_chekhov_guns` 与 `active_misunderstandings`：设计本章针对性推进或引爆点；
- 提取 `genre_profile`：确认当前题材的基调策略、配比基线、断章风格，按题材调整细纲节奏。

## 二、 单章核心看点与读者心理欲望检核 (Chapter Core Hook Matrix)

推演单章细纲时，根据具体情境自适应设计看点（包含但不限于以下维度，鼓励自由组合与个性化设计，不设死板配额，尊重故事自然心流）：

1. 💥 **【认知破局 / 非对称降维】**：主角展现远超对手想象的独特理解、意外破局机制或底层法则颠覆；
2. 💰 **【价值兑现 / 筹码沉淀】**：实打实获取关键线索、图纸、核心资财、地缘准入特权或点数沉淀，杜绝虚无自嗨；
3. 🤝 **【利益交锋 / 人际机锋】**：高段位角色间的言语机锋、筹码拉扯、利益捆绑或心理防线瓦解；
4. 💎 **【人物厚度 / 多维软肋】**：配角展现真实的世俗牵挂、生存软肋、反差性格或利益算盘，赋予角色独立灵魂；
5. 🎣 **【即时危机 / 断章钩子】**：在章末抛出突发异动、身份暴露隐忧、倒计时炸弹或深层暗流，拉满抓心感（断章风格由 `genre_profile.ending_style` 控制）；
6. 🎭 **【双重视角 / 降维马甲反差】**：巧妙利用信息差，在各方势力的惊疑、误判与暗中推演中释放戏剧反差爽点；
7. 🔬 **【硬核工匠 / 技术秩序美感】**：研制配伍、工艺淬火、结构铭刻、代码调试、战术推演的微观精妙过程，展现专业降维的技术美学；
8. 📜 **【规则破译 / 智性解密快感】**：面对诡异险境或严酷考核，通过冷静试错与逻辑推演找到死穴机制；
9. 🛡️ **【公道伸张 / 秩序重塑共鸣】**：以成熟手段打破不公规则、击溃体制压迫、庇护同行者，带来深沉的情感宣泄；
10. 🌌 **【岁月沧桑 / 心境顿悟跃迁】**：在世事波折与历史沉浮中参悟机理，心境获得洗礼与跃迁；
11. 💖 **【情感共鸣 / 关系发展】**：角色间的情感张力、信任建立、误会解除、关系突破（言情/治愈系/全题材调剂）；
12. 🌿 **【日常治愈 / 生活细节】**：美食美景、萌宠互动、温暖人际、生活小确幸（治愈系/轻小说/全题材调剂）；
13. 🌟 **【开放式自主看点】**：依据当前题材特色，自主创新设计专属的核心看点。

## 三、 单章 4 维正交积木拼装体系 (Modular 4-D Chapter Assembly)

> 💡 **【自由拼装与自主创新原则】**：
> 严禁机械套用固定流程！推演细纲时，从以下 4 个正交维度中**各选 1 块积木自由拼装（如 入口1A + 引擎2D + 折叶3C + 余韵4A）**。**如果 AI 自己有更好的想法，完全可以自行构造出更合理的规划与设计，无需生硬采纳以下固定选项**。

1. 🧱 **【维度一 · 镜头切入积木】**
   - 入口 A（局部微动作/特写）/ 入口 B（环境压迫与声光先兆）/ 入口 C（第三方侧面视线）/ 入口 D（激烈机锋中途切入）/ 入口 E（账册复盘与暗中盘算）/ **入口 X（🌟 自行构造的全新切入镜头）**
2. ⚙️ **【维度二 · 推进拉扯引擎】**
   - 引擎 A（密闭脱水对峙）/ 引擎 B（多线平行剪辑）/ 引擎 C（幕后递刀与内讧自爆）/ 引擎 D（市井烟火与暗线拼图）/ 引擎 E（硬核工艺与机制解析）/ 引擎 F（规则解密与逻辑破译）/ 引擎 G（情感张力与关系博弈）/ **引擎 X（🌟 自主独创的核心推进机制）**
3. 🌪️ **【维度三 · 意外变量折叶点】**
   - 折叶 A（第三方不速之客强行介入）/ 折叶 B（既定规则底层突变）/ 折叶 C（敌人翻出隐藏死人开关）/ 折叶 D（信息差戏剧性过度脑补）/ 折叶 E（主动示弱反手合围）/ 折叶 F（情感误会意外爆发）/ **折叶 X（🌟 结合世界规则自主设计的意外转折）**
4. 🎣 **【维度四 · 收尾余韵与钩子】**
   - 余韵 A（战利品即时战备转化）/ 余韵 B（电影级镜头留白定格）/ 余韵 C（倒计时炸弹紧迫压顶）/ 余韵 D（配角认知颠覆与震撼失语）/ 余韵 E（远方伏笔引信暗燃）/ 余韵 F（情感余韵与温暖收尾，治愈系/言情适用）/ **余韵 X（🌟 独创的个性化情绪余韵与留白）**

## 四、 核心机制演化与多样性法则 (Realistic Mechanics & Stakes Depth)

若本章涉及模拟推演、技能升级、研发制作、比赛训练、调查推理等，细纲**严禁写成干燥的履历式流水账或单纯的数据面板堆砌**，必须贯穿以下真实体验：

1. 🌾 **【微观生存颗粒度与环境风貌】**：展现具体的生活与环境细节（地方风俗、方言物产、世俗生计、科技质感、时代氛围），赋予叙事真实的厚度与温度；
2. 🤝 **【核心情感羁绊与命运交织】**：设计非工具人化的同袍、伙伴、长辈、爱人羁绊，让读者产生真实共情；
3. ⚖️ **【核心抉择与真实代价】**：面临具体危机与资源争夺时的取舍，**有坚守必有代价，绝无廉价全收**；
4. 💔 **【波折沉淀与磨砺突破】**：有机穿插挫折、瓶颈或代价损耗；核心能力跃迁**通常**源于漫长专注与生死领悟（或对应题材的等价积累）；若本书采用“顿悟/奇遇/陡变”型成长，需让过程或代价支撑得起来；
5. 🧠 **【身心负荷与心智锚定】**：高能爆发与能力突破后，规划体能/装备/资源/情感/心理的真实损耗与恢复，坚守角色自身之本心。

## 五、 反派厚度与危机铺垫 (🔒 T0 判据 + 📐 T1 默认)

1. **反派/对手有动机、有后手（T0 判据）**：
   - 敌人不能是单纯无脑叫嚣送死的木桩——这本质是“反低智化”判据，不是“所有反派都必须有复杂人格”。
   - 核心反派通常有合乎其利益的动机与后手（反抗尝试/保命底牌/通风报信的“死人开关”）；**让反派“彻底失败且无后手”也有效**，前提是这一结局被主题与节奏需要（不是为爽而爽）。
2. **危机铺垫（📐 默认）**：
   - 通常：重大危机/突发事件爆发前，前 1~2 章放 1~2 处隐性铺垫（流言、反常物象、资金链紧绷、暗桩失联、环境异常等）。
   - **可破**：突击型、信息不对称型、规则怪谈型可少铺垫甚至零铺垫，只要事后回看能自圆其说；不要为“满足铺垫数”而硬塞无用线索（那会变成另一种套路）。

## 六、 ABC 多走向分支推演协议 (Branching Protocol)

向用户汇报或自主决断时，推演 **3 个不同风味的走向方案**（数量亦可按场景 2~4 个，重点是“风味不同”而非固定 3 个），优先遵循长线叙事与反路径依赖法则：
1. 🌌 **长线叙事深层布局 (Long-Arc Epic Depth)**：细纲**尽量不要**只顾单章快感而写成割裂快餐；每个走向**最好**标明其在中长线（卷/幕/全书，视本书规模而定）中所承担的因果砖瓦——**也可以是有意“只为制造一个瞬间”的走向**，只要它与前后文能咬合；
2. 🎨 **破除情节路径依赖 (Anti-Path-Dependency)**：推演走向时主动规避"挑衅->秒杀"等公式化陈词滥调，探索更具节奏感、拉扯感的方向。；
3. **每个选项结构标明**：
   - 🧱 **4 维积木拼装公式**：明确声明选用的结构组合（例如：入口 1A + 引擎 2D + 折叶 3C + 余韵 4A）；
   - 🎯 **破局手段**：自适应选用大破局库（包含但不限于：规则反噬/雷霆爆发/信息暗战/利益招安/掀桌自救/攻心诛心/因果借势/示弱诱敌/情感杠杆/时间差等，允许自由创新例外战术）；
   - 🧠 **角色心智演进**：本章触发的关键认知破裂与心智跃迁；
   - 🕸️ **伏笔与信息差推进**：本次推进/回收的旧伏笔与新埋下的中长线暗流；
   - 🔒 **全书闭环承诺**：埋下的因果线索必须可回收，或明确登记为长线（与 AGENTS「伏笔闭环」护栏一致）。

## 七、 走向决断机制 (Autonomous Decision)

由人类导演或总策划 Agent 评估并选定其中戏剧张力最强、逻辑最严密、最符合题材调性的最优选项，写入 `novel_workspace/03_outlines/vol_xx/beats/ch_xxx_beats.md`，并启动正文起草流水线。

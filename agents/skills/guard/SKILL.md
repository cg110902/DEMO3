# SKILL — guard（审校=重铸，一次性）

你在流水线第 3 站，是这一章的**第二位作者**：审校不是校对，是带着护栏的完整再创作
（裁决记录见 workflow#Stage 3）。交付即销毁；你写下的 final 就是这本书的记忆本身。

## 使命

产出一篇你肯署名的定稿：`final/ch_XXX.md`，并在注记里逐条证明「验收」已被正文兑现。
raw 不可救时，写拒收报告也是尽职。

## 输入

- 任务书 + 最新 raw + pack P0（世界此刻状态、上章余温）+ evidence 只读自跑权：
  `python studio.py evidence style|dup|mentions|gaps|words`（按需，纯 JSON 数字）。
- 判据词汇不够时查 `craft#审校判据`、`craft#句式与语域词汇`。

## 动作

1. 先核事实后论文笔：任务书「目标/必须保留」对 raw 逐条核——事实层硬伤（越界知情、
   数字不符、线没动）任何文笔都救不了，直接跳第 5 步评估拒收。
2. 结构重铸权全用：场序、切分、开头结尾、节奏都可推翻（与 raw 同构 = 你没干活）；
   风格旋钮按 front-matter 执行，起草没执行到位的（句长/段首证据在 evidence style），改。
3. 逐句清洗：tic 命中清零或说明保留理由；evidence dup 报出的复制级重合逐处消解；
   比喻与语域按 craft 的本书定调核对。
4. 写 `log/review/ch_XXX.md`：「验收」逐条打钩 + 每条一行证据（正文引文或 evidence
   字段=数值）；再补一段「我重铸了什么/为什么」三到五行——这是给 director_log 回流的原料。
5. 拒收判定（raw 不可救：事实硬伤+结构性塌陷同时存在）→ 只写 `log/review/ch_XXX.reject.md`
   （缺什么语境/需要主控修 beats 还是补 pack），不动 final。
6. 交付前最后一遍：只读出声，不回改内容——读不顺才微调句子。

## 输出

`final/ch_XXX.md`（纯净正文，不带任何工程注记）+ `log/review/ch_XXX.md`。两件必须同时交。

## 禁区

不得违反「目标」「必须保留」；不碰 raw（它是审计件）；不碰 state/（状态回流经提案，由
Stage 4 处理，你只负责在注记里**列出**"本章使 X 知道了 Y"这类待同步事实）；
不写"人物动机不够强"式空话注记——形容词判据 = 未审。

## 退回与拒收

同章拒收有次数上限（workflow#拒收语义），拒收不是逃生门：能救就救，救的成本高于重写时
才拒。你无权要求补派或改任务书——那是主控的工位。
